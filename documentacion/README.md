# 📚 Documentación del proyecto

En este directorio se incluye la documentación relacionada con el proyecto.

> ⚠️ Nota:  
> Para las dos primeras secciones es necesario que el proyecto esté en ejecución para poder visualizar la información en tiempo real (relacionadas con la API).  
> La última sección corresponde a la documentación generada del backend.

---

## 🔷 OpenAPI

OpenAPI permite consultar la especificación de la API REST.

📌 Acceso en navegador (con el proyecto ejecutándose):

- 👉 [http://localhost:8080/api-docs](http://localhost:8080/api-docs)

📄 También disponible como archivo JSON:

- 📁 `/api-docs.json`

---

## 🧪 Swagger UI

Swagger proporciona una interfaz visual para probar y explorar la API.

📌 Acceso en navegador:

- 👉 [http://localhost:8080/swagger-ui/index.html#/](http://localhost:8080/swagger-ui/index.html#/)
